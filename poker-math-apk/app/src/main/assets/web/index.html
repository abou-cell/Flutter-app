Guide rapide

Seuil du call = call ÷ (pot + call). Votre équité doit dépasser ce seuil pour qu'un call soit rentable dans ce modèle.

EV du call = équité × (pot + call) − call. Une EV positive signifie une valeur moyenne positive si la même situation était répétée de nombreuses fois.

Équité = part moyenne du pot obtenue dans les simulations, pots partagés inclus.

Outs = cartes non vues qui améliorent votre catégorie de main au prochain tirage.
